# KubeScope v1.0.1 — offline demo distribution

This is the **offline, demo-only** preview. It is a small standalone HTML file: extract the attached `KubeScope-v1.0.1-OFFLINE-DEMO.zip` and open `index.html`.

- Fictional sample clusters, namespaces, nodes, workloads, and events
- Interactive topology, filters, detail panels, and sample command output
- Light and dark themes
- No server, kubectl, kubeconfig, cloud access, or telemetry
- No network calls, browser storage, clipboard access, or command execution
- Content Security Policy explicitly disables connections

**Important historical note:** The `v1.0.1` Git tag predates this hardening and still refers to the earlier development source. Do not use its source archive for no-impact demo testing. Download the specially named **OFFLINE-DEMO** zip instead.

This is a preview of the user interface, not a production-ready Kubernetes management tool.
